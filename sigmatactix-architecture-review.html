Deepen Vault Ingestion into a Unified Document Intake Module

Files: server.ts, src/pages/SecondBrain.tsx, src/lib/api.ts, src/data/secondBrainVaults.ts
Problem

Document uploading, text extraction, Gemini synthesis, and vault persistence are scattered across shallow endpoints and client state, forcing the UI to orchestrate four distinct steps across an ad-hoc seam.

Solution

Collapse upload, multimodal text extraction, classification heuristics, and pgvector embeddings into a single deep VaultIngestionModule behind one interface.

Decompose Monolithic server.ts into Deep Domain Modules

Files: server.ts (6,217 LOC) → src/server/telemetry, src/server/agents, src/server/vaults
Problem

A single 6,217-line server file handles disparate responsibilities (Stripe billing, telemetry metering, agent loop, second brain, DNS verification), creating extreme divergent change and no modular seams.

Solution

Extract four deep modules (VaultModule, AgentRuntimeModule, TelemetryModule, BillingModule) that encapsulate state manipulation behind minimal, typed interfaces.

Replace Repeated Model Provider Switches with an AIProvider Adapter Seam

Files: server.ts, src/pages/Tenants.tsx, src/lib/agentResolution.ts
Problem

Provider cascades (Gemini, OpenAI, Anthropic, DeepSeek) recur across six files with custom header wiring, error handling, and prompt interpolation.

Solution

Standardize on a deep InferenceProvider interface that hides provider-specific HTTP headers, token logging, and model parameters.
