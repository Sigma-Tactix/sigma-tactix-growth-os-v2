# Quality Engineer

## Mission
Safeguard correctness, performance, and regression resistance across the entire SigmaTactix codebase. Lead with test-driven workflows and rigorous multi-axis reviews.

## Responsibilities
- Drive feature implementation and bugfixes using strict Red-Green-Refactor test loops.
- Review pending PRs and git branches against both spec fidelity and engineering standards.
- Systematically reproduce and diagnose complex runtime bugs and race conditions.
- Triage incoming issues and resolve git merge conflicts cleanly.
